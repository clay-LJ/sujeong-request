# 수정요청서

이미지, PDF, PPTX를 브라우저에서 열고, 원본 위에 번호를 찍어 번호별 수정 요청을 작성하는 한국어 정적 웹 도구입니다. 원본 페이지·번호·요청 내용이 들어간 A4 PDF를 저장합니다.

## 실행

Node.js 22 이상에서 `npm ci`, `npm run dev`를 실행합니다. `npm run build`로 `dist/`를 만들며, 상대 경로로 GitHub Pages 하위 경로에서도 동작합니다. `npm run preview`로 빌드 결과를 확인합니다.

`npx playwright install chromium`으로 테스트 브라우저를 준비하고 `npm test`로 실제 브라우저 검증을 실행합니다. `BASE_URL=https://… npm test`로 공개 배포도 시험합니다. 테스트는 합성 파일만 사용합니다.

## 사용

1. 이미지·PDF·PPTX 파일 하나를 선택합니다.
2. 페이지를 이동하고 수정 위치를 클릭합니다.
3. 번호별 요청 내용을 입력합니다. 내용 편집·번호 삭제가 가능합니다.
4. 표지가 필요하면 **표지 설정 → PDF에 표지 추가**를 선택합니다. 회사 로고(PNG·JPEG·WebP, 최대 5MB), 프로젝트명, 수신·발신, 전달 문구를 선택해 입력할 수 있습니다.
5. PDF 내보내기로 저장합니다. 문서 제목이 파일명에 적용되며 미입력 요청은 PDF에 표시됩니다.

좌표는 페이지 폭·높이에 대한 비율로 유지되므로 확대와 화면 크기가 변해도 원본의 같은 위치를 가리킵니다. 다른 페이지의 요청도 오른쪽 목록에 표시되며 페이지 링크로 이동합니다.

## 개인정보와 보관

원본 파일은 브라우저 메모리에서만 읽습니다. 업로드 API, 백엔드, 원격 저장, 분석 도구, 쿠키, localStorage, 서비스 워커가 없습니다. 라이브러리·글꼴·PDF 지원 파일은 사이트와 같은 출처에서 제공됩니다. 외부 연결 PPTX 미디어는 렌더러 정책과 CSP로 차단합니다. GitHub Pages는 사이트 파일을 제공하면서 일반 접속 정보를 처리할 수 있지만, 앱은 선택한 원본이나 요청 내용을 전송하지 않습니다.

탭을 닫거나 새로고침하면 작업이 사라집니다. 필요한 결과는 PDF로 저장해 주세요. 새 파일 선택 시 현재 작업 삭제를 확인합니다. 저장된 PDF에는 원본과 요청 내용이 포함되므로 사용자가 전달 대상을 판단해야 합니다.

## 지원과 한계

- PNG·JPEG·WebP·GIF 첫 프레임, 다중 페이지 PDF, 현대 PowerPoint `.pptx` 직접 가져오기.
- 파일 하나 최대 40MB, 최대 60페이지, 이미지 5천만 픽셀 이하. 미리보기는 긴 변 약 1800px 이하로 래스터화합니다. 큰 문서는 기기 성능에 영향을 받습니다.
- PPTX는 PowerPoint와 동일한 렌더링을 보장하지 않습니다. 글꼴 대체·줄바꿈·일부 표·차트·SmartArt·효과·수식·EMF/WMF에 차이가 생길 수 있습니다. 실제 업무 파일은 미리보기에서 확인하세요.
- 애니메이션·전환·3D·실행형 OLE·슬라이드 노트·암호 파일·구형 `.ppt`는 지원하지 않습니다. 외부 연결 미디어와 EMF 내장 PDF 미리보기는 비활성화했습니다.
- PDF는 표시된 페이지를 사용하며 PDF 양식·첨부파일·주석 편집은 제공하지 않습니다.
- 출력 PDF는 한글 외형 보존을 위한 **이미지 기반 PDF**입니다. 텍스트 선택·검색·접근성 태그와 원본 편집 정보는 제공하지 않습니다. 긴 요청은 추가 페이지로 이어집니다.
- 공동 편집·링크 공유·작업 재개 파일·자동 저장은 이번 초안에 없습니다.

## 구성

PPTX: `@aiden0z/pptx-renderer` 1.4.0의 ZIP 파싱·모델·DOM 렌더링. 외부 미디어 차단 및 권장 ZIP 한도를 적용합니다. PDF: PDF.js 6.5.438. PPTX 미리보기 캡처: html-to-image. PDF 생성: jsPDF. 한글: 자체 호스팅 Noto Sans KR. 라이선스는 `public/THIRD_PARTY_NOTICES.txt`와 npm 패키지 원문을 확인하세요.

`tests/fixtures/`에는 합성 한글 텍스트·표·도형으로 만든 PPTX 3장, PDF 2장, 이미지가 있습니다. 고객 자료·사용자 실제 파일은 저장소에 포함하지 않습니다.

## 배포

새 전용 공개 저장소의 `main` 변경을 `.github/workflows/pages.yml`이 빌드하여 GitHub Pages에 배포합니다. 인증 토큰은 코드나 설정 파일에 넣지 않습니다. Pages Source는 GitHub Actions입니다.
